# Data Analysis

This project performs exploratory data analysis and builds a decision tree classifier to classify Iris flower species using the famous UCI Iris dataset.

## Contents
- **Week 11**: Dataset overview, summary statistics, correlation analysis, and visualizations
- **Week 12**: Decision tree model training, prediction, and evaluation with accuracy, precision, and recall

## Libraries Used
- pandas, NumPy, Matplotlib, Seaborn, scikit-learn
